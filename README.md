# FitLog · 健身打卡本（PWA 版 · 可安装 · 离线 · 支持多人档案）

## 两种用法

### A. 单文件版（最简单）
直接用 Chrome / Edge 打开 `/workspace/fitness_tracker.html` 即可。双击可用，数据存在浏览器本地。

### B. PWA 版（推荐手机长期使用）
本目录是「可安装 + 离线」版本。需通过本地服务器打开（手机不能直接双击 html 安装）：

1. 在本目录执行：
   python3 -m http.server 8080
2. 电脑浏览器访问 http://localhost:8080
   - 点地址栏右侧「安装」图标 → 添加到桌面/应用；之后离线也能用。
3. 手机使用（同一局域网）：
   - 电脑和手机连同一个 Wi-Fi；
   - 手机浏览器访问 http://<电脑内网IP>:8080 （如 http://192.168.1.20:8080）；
   - iPhone：Safari 分享 →「添加到主屏幕」；安卓：Chrome 菜单 →「安装应用」。
   - 安装后离线可用，数据存在手机本机。

## 界面导航（D 版 · 底部 tab bar）
导航固定在屏幕**底部**，拇指区一触即达，共 6 格：

- **一级页（前 5 格）**：今日 / 体重 / 训练 / 饮食 / 进度 —— 每天要用的都在这五个里。
- **「更多」（第 6 格）**：参考手册 / 数据同步 / 档案管理 / 回收站 —— 低频功能收进一个**真实页面**。
  点「更多」直接切到该页面（不是悬浮面板，因此**不会盖住任何内容**）；进入任一二级页时，底栏的「更多」会高亮。

另有快捷操作：
- **今日页顶部「快速记录今日体重」**：一行填完直接保存，不用先跳去「体重」页。今天已记过的话，输入框会回填当天数值、按钮变成「改」，再点一次即覆盖（不会重复记录）。
- **左右滑动 / 方向键**可在 10 个页面间切换。
- **体重历史默认只显示最近 5 条**，下面有「展开全部 N 条」按钮，避免记录多了把页面拉得很长。
- 内容较长时右下角出现**返回顶部**按钮，位置抬到底栏之上，不会挡住导航。

## 多人档案
顶栏头像可切换档案，「档案管理」（在「更多」里）可按人设置性别、年龄、身高、起始/目标体重、活动系数与每日摄入目标。
各档案的体重、训练、饮食、照片独立保存、互不干扰。

### 预设卡通头像
档案页有「头像」卡片，12 款内置卡通头像一点即换：狐狸 / 猫 / 熊猫 / 熊 / 考拉 / 兔子 / 小狗 / 企鹅 / 青蛙 / 老虎 / 猴子 / 猫头鹰。
另有一格「字母」可切回原来的首字母样式。

- 全部用**内联 SVG** 手绘（不依赖 emoji 字体），所以在 iOS / Android / Windows 上长得完全一样，观感统一。
- 头像随档案保存（`profile.avatar`），导出 JSON 时一并带走。
- 老档案（没有头像字段）在首次打开时按档案名 hash **稳定分配**一个——同一个名字永远是同一张脸，不会每次刷新换。
- 新建档案会自动随机分到一个头像，之后可随时改。

## 数据同步
两种版本数据都存浏览器本地（localStorage）。换设备时：
应用内「更多」→「数据同步」→ 导出 JSON（含全部档案）→ 传到新设备 → 导入即可。

## 界面设计说明（D 版 · 紧凑控制台）
界面为单文件、零依赖实现：全部样式集中在 `index.html` 顶部的 `<style>` 里，用 CSS 变量统一管理配色、圆角、阴影与字号，没有构建步骤、没有外部依赖。
- 冷灰白底 `#f6f7f9` + 单一蓝色主色 `#2a62c4`，点缀暖橙 `#d9560f`；状态另有语义色（达标绿、接近琥珀、超标红）。
- **指标改为表格化**：饮食与体重进度是一张列对齐的表（项目 / 实际 / 目标 / 百分比），等宽数字右对齐、行内嵌细进度条，一屏纵向看全，取代原来的卡片堆叠。
- **导航改为底部 tab bar**（`position:fixed` + `env(safe-area-inset-bottom)`）：`body` 预留等高底部内边距，返回顶部按钮抬到 tab bar 之上。
- 密度更高、字号基线更小；区块标题改为小号灰色全大写标签；阴影基本取消、圆角收紧。
- 触控目标按移动端标准（tab 最小 44px 高，输入框 / 按钮多为 40–44px 高）。
- 头像有两种形态：内置 SVG 卡通头像（默认）与「首字母 + 渐变」。
  `.avatar` 的白缝和描边用 `box-shadow` 画在**盒外**（不再用盒内 `border`），
  这样圆形内容区是完整的 16px——否则卡通头像的耳朵会被边框切平。

- manifest.webmanifest  PWA 配置

## 改版选型（design/redesign-options.html）

> **已选定：D 紧凑控制台**，并已据此重构 `index.html`（详见上方「界面导航」与「界面设计说明」）。

应用要换一套视觉方向时，先在这个文件里挑，不要直接改 `index.html`。
它用**同一套模拟组件 + 四套主题令牌**渲染「今日 / 训练 / 进度」三屏，四版的方向差异：

| 方案 | 气质 | 密度 | 导航 | 改动幅度 |
|---|---|---|---|---|
| A 极简数据流 | 克制、工具感，发丝线取代卡片 | 中低 | 顶部 tab | 中 |
| B 深色霓虹 | 近黑底 + 霓虹青绿，OLED 省电 | 中 | 顶部 tab | 大 |
| C 温暖手账 | 暖米色 + 大圆角 + 衬线标题 | 中低 | 顶部 tab | 小 |
| D 紧凑控制台 | 表格化 + 等宽数字，一屏看全 | 高 | **底部 tab bar** | 中 |

四个主题各自完整定义了 19 个 `--m-*` 令牌（色板 / 圆角 / 阴影 / 字号 / 内边距）。
选定后重构 `index.html` 时，主要就是把对应那组令牌搬进 `:root`，再按该版的「结构性差异」段调整组件规则——
数据层、业务逻辑、9 个页面结构都不需要动。

导航形态与视觉风格是独立的：A/B/C 也可以用 D 的底部 tab bar，属于合法的混搭。

## 自动更新（重要）
PWA 已内置自动更新：每次重新部署（重新生成 fitness-app/ 目录）时，`sw.js` 会带上新的版本号，已安装的 PWA 在下次打开时**自动检测新版本并静默刷新**，无需重新“添加到主屏幕”。
- 联网时：页面始终拉取服务器上的最新 index.html（网络优先）。
- 离线时：回退到上次缓存的版本，仍可正常使用。
- 部署新版本后，旧用户最迟在「下一次打开 App」时即看到新功能；若当时页面正开着，会自动刷新一次。
