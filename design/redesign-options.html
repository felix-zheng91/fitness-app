改版方案 · 4 版对比

FitLog 整体设计 · 四版方向样张

四版不是换配色，而是四种不同的设计取向——排版范式、信息密度、色彩策略、导航形态都不同。每版都用真实内容渲染了「今日 / 训练 / 进度」三个核心屏，可以直接对比判断。

四版都保持现有技术前提不变：零依赖单文件、无构建步骤、9 个页面结构不动、数据层与全部业务逻辑一行不改。

屏内数字为示意数据（按应用自身的算法口径造：TDEE 约 2100、缺口 450 kcal、蛋白 2.0 g/kg）。只用于判断版面与观感，不代表你的真实记录。

A 方案一

极简数据流

数据即界面。用发丝分割线和大面积留白取代卡片边框与阴影，让数字成为唯一的主角。 字号对比拉得很开——关键数字 52px、辅助文字 10.5px——层级不靠颜色而靠尺度。 气质接近 Linear / Vercel 那类工具：克制、干净、久看不累。

B 方案二

C 方案三

温暖手账

延续现有的暖米色基因，但把它做得更彻底：大圆角（20px）、柔和弥散阴影、墨绿加陶土橙， 分区标题改用衬线字，列表用虚线分隔、动作带序号圆牌。整体像一本纸质的训练手账—— 亲和、耐看、不那么「数码」。

D 方案四

紧凑控制台

重构时会做什么
  • 导航从顶部双行 tab 改为底部 tab bar（5 个一级页 + 更多，共 6 格）

  • 底部 tab 与 iOS 手势条、安卓返回手势区需要额外留安全边距
  • 表格化布局在窄屏（360px 以下）需要降级为两列
≡ 横向对比

四版放在一起看

如果只看一个维度，看「信息密度」和「气质」这两列就够了——它们决定了你每天用它的感受。

方案气质信息密度色彩策略导航形态改动幅度最适合
A 极简数据流 克制、干净、工具感 中低 · 一屏约 6 项 纯白 + 单一绿点缀，靠明暗对比 顶部 tab（不变） 中 喜欢安静界面、不介意多滑两下
B 深色霓虹 有型、张扬、夜店感 中 · 一屏约 8 项 近黑底 + 霓虹青绿，发光表达进度 顶部 tab（暗色版） 大 多在晚上/健身房用，看重观感冲击
C 温暖手账 温和、耐看、纸感 中低 · 一屏约 6 项 暖米色 + 墨绿 + 陶土橙 顶部 tab（不变） 小 想保留现有调性，只要「更好看一点」
D 紧凑控制台 冷静、密度高、专业工具 高 · 一屏约 12 项 冷灰白 + 单一蓝，颜色只用来标状态 底部 tab bar（新） 中 想一屏看全、单手操作、效率优先

怎么挑：问自己三个问题

  1. 你主要在什么时间、什么场景打开它？ 晚上 / 健身房 / 光线暗 → 倾向 B；白天随手记 → 倾向 A 或 C。
  2. 你更在意「好看」还是「一眼看完」？ 好看 → A / B / C；一眼看完 → D。
  3. 你能接受多大的视觉改动？ 想稳一点就 C（和现状最接近）；想彻底换个面貌就 B。

另外一个可以「混搭」的地方：A / B / C 也可以换成 D 的底部 tab bar——导航形态和视觉风格是两件独立的事。 比如「C 的配色 + D 的底部导航」也是个合理组合，你如果倾向某种混搭，直接说就行。
